# Проверка базового API — 8 октября 2026

Среда: Python 3.12, PostgreSQL 16.15, зависимости из requirements.txt/requirements-dev.txt. PostgreSQL использовался в отдельной одноразовой БД.

- SQLite с включёнными внешними ключами: **32 теста успешно**.
- PostgreSQL: **32 теста успешно**.
- Обе Alembic-миграции применены на пустой PostgreSQL БД.
- Seed запущен дважды: сохранились 30 пользователей и 100 заявок, дубликатов нет.
- Дополнительный тест проверил обновление старого demo_hash и сохранение настоящего пароля при повторном seed.
- Реально запущен Uvicorn. Через HTTP проверены Swagger, вход, категории, создание, чтение, изменение заявки и отказ без токена.
- Проверены компиляция Python, зависимости, формат diff и базовые статические проверки новых модулей.

Автотесты проверяют изоляцию заявителей, валидацию и запрет подмены служебных полей, пагинацию, срок обработки, истечение/повреждение JWT, блокировку пользователя, редактирование только новой заявки, атомарность заявки и аудита при имитации отказа БД.

Есть предупреждение Starlette об устаревании httpx в TestClient. Оно не влияет на результаты; httpx используется только для тестирования.

Нагрузочное тестирование и внедрение в рабочую университетскую среду не выполнялись. PostgreSQL 15 и Python 3.13 указаны в конфигурации GitHub Actions для последующих прогонов.
